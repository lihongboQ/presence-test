# COVE — Product shopping demo

English-market shopping experience built with React + Vite + TypeScript.

## Run

```bash
npm install
npm run dev
```

## What’s included (P0)

- Catalog with responsive grid (18 mock products)
- Keyword search, category filter, featured / price / rating sort
- Product detail with variants, qty, add-to-cart feedback
- Cart: update qty, remove, clear, subtotal / shipping / tax / total
- Cart persistence via `localStorage`
- i18n: English (default) + Spanish toggle
- Loading / empty / error-friendly states

Currency: **USD**. Free shipping estimate over $75; tax estimate 8%.
